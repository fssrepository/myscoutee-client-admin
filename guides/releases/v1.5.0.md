# MyScoutee Admin 1.5.0

Release aligned with the MyScoutee 1.5.0 build. The application sources live in
`src/`, the native DEB builder in `packaging/`, and the manual and its PDF
builder in `guides/manuals/`. `VERSION` owns the package version.

The existing private admin API, local control-token boundary, in-memory
credentials, desktop notifications and disconnected startup behavior are
unchanged. The release includes the Debian installer, API manual and SHA-256
checksums. Runtime tests and installer-content verification run before upload.
